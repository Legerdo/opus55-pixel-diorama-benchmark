# Pixel Art Diorama Prompt Benchmark

Four independent Claude Opus 5.5 runs at high reasoning effort generated the same 320×180, eight-second animated scene. The prompt conditions are Baseline (A), Pixel Craft (B), Art Direction (C), and Self Review (D).

This is one sample per condition. The comparison page does not assign a winner.

[View the comparison](https://legerdo.github.io/opus55-pixel-diorama-benchmark/)

Only the public HTML results are deployed from `docs/`. Session logs, agent configuration, prompts, local paths, and browser captures are not published.
