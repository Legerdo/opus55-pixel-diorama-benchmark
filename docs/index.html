추가 pixel-art quality 규칙:

- 모든 final coordinate를 integer pixel grid에 맞춘다.
- sub-pixel rendering과 anti-aliasing을 사용하지 않는다.
- 약 24~32개의 제한된 core palette를 사용한다.
- isolated pixel보다 coherent pixel cluster를 우선한다.
- 형태는 silhouette → large shape → medium cluster → selective detail 순서로 구성한다.
- 모든 영역에 동일한 detail density를 적용하지 않는다.
- orphan pixel과 noisy dithering을 최소화한다.
- smooth gradient와 blur에 의존하지 않는다.

Pixel-art quality:

- integer pixel grid
- no sub-pixel rendering
- no anti-aliasing
- 24~32색 core palette
- coherent pixel cluster
- silhouette → large shape → medium cluster → selective detail
- orphan pixel과 excessive dithering 최소화
- no blur / smooth gradient

Art direction:

- primary focal point는 wizard + cauldron이다.
- secondary focal point는 cat + lantern이다.
- background는 focal plane보다 contrast와 detail density를 낮춘다.
- foreground / midground / background가 명확하게 구분되어야 한다.
- cyan magical light와 warm amber light를 서로 다른 light source로 일관되게 처리한다.
- brightest highlight는 focal area에 제한한다.
- foreground foliage를 framing에 활용한다.
- 장식의 양보다 composition, silhouette, color hierarchy를 우선한다.
